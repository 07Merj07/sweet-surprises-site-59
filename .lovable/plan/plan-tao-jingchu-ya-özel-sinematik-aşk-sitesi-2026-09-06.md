# Plan: Tao Jingchu'ya Özel Sinematik Aşk Sitesi

A romantic, full-screen cinematic love-letter website for Tao Jingchu, designed to feel like a personal film.

## Goal
Build a single-page, immersive English-language experience that cycles through photos in a cinematic way, highlights the special date March 1st, and uses the nickname "Baobao". A background song will play automatically (with user control).

## Requirements locked by user answers
- Visual style: Cinematic / love-film atmosphere
- Language: English
- Name on site: Tao Jingchu
- Special date: March 1st
- Nickname to include: Baobao
- Background music: yes, song to be chosen later

## Steps

1. Gather remaining content
   - Ask user to upload photos of Tao Jingchu / the couple.
   - Ask user to pick the background song (Spotify/YouTube link or audio file).
   - Ask if they want a short message text from them, or if I should write it.

2. Create 3 cinematic design directions
   - Generate three full-screen photo-film style previews.
   - User picks one.

3. Build the chosen direction
   - Full-screen hero/photo sections with smooth transitions.
   - Typography-led romance copy in English including Tao Jingchu, Baobao, March 1st.
   - Ambient gradient overlays and subtle motion.
   - Background music integration with a visible play/pause toggle.
   - Responsive layout and touch support.

4. Add personalization
   - Write or use the user's love note.
   - Place the special date and nickname meaningfully in the flow.

5. Verify
   - Run typecheck/build.
   - Check preview on desktop and mobile.
   - Confirm music plays on interaction where browsers require it.

6. Deliver
   - Share preview link and any notes about autoplay rules.
